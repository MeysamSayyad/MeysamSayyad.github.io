## Why

The project README is minimal and does not clearly explain what this resume app is, how it is structured, or how to run it locally. A stronger README makes the project easier to understand for visitors, collaborators, and recruiters while also giving proper credit to the creator behind the work.

## What Changes

- Expand the project README to explain the purpose and features of the VS Code-inspired resume portfolio.
- Add clear setup, installation, and build/run instructions for local development.
- Credit the project author and explain the overall design direction and stack.
- Keep the documentation focused on the actual project, not the in-app resume UI labels.

## Capabilities

### New Capabilities
- `project-readme`: Defines the project-level documentation needed to explain the application, its stack, and local development workflow.

### Modified Capabilities
- None.

## Impact

- Repository documentation and developer onboarding.
- Local setup clarity for running and building the app.
- Improved presentation of the project for GitHub visitors and potential collaborators.
